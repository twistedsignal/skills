# twistedsignal/skills
A small collection of skills for Roblox development

## Scaleable UI
Uses a module to scale your UI accurately for all screen sizes

### Installation:
#### Prompt
```md
Run `npx skills use "https://github.com/twistedsignal/skills" --skill "scaleable-ui"` and follow the generated skill instructions now. Read its complete output, redirecting it to a temporary file first if necessary. Resolve relative paths from the supporting-files directory it provides.
```
#### Command (may not work correctly)
```sh
npx skills add https://github.com/twistedsignal/skills --skill scaleable-ui
```
